# Simulation App · Registro de entradas y salidas por bloque

Aplicación web (un solo archivo `index.html`) para la toma de datos de la asignatura de Simulación – Universidad de La Guajira.

- **Bloque**: identificación (Hoja 2) y parámetros estructurales (Formato 1).
- **Registro**: botón de llegada con hora exacta (columna A) y seguimiento de filas sombreadas (B inicio atención, C fin atención, D salida, servidor, AB/PE/PR).
- **Cortes**: conteo cada 10 minutos con alarma (Formato 3).
- **Resumen**: Formato 4, lista de revisión, métricas (λ, espera, atención, tiempo en sistema, utilización) y tabla de consolidación con valores para Unity.
- **Datos**: exportación a Excel (`Zona_Bloque_Pareja.xlsx`), CSV y respaldo JSON.

Los datos se guardan en el navegador (localStorage). Abrir `index.html` o publicarlo con GitHub Pages.
